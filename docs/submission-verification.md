# Submission verification

Assignment ID: `Fullstack-ClaudeGemini-UsageConnector-v1`.

## Package overview

The submission contains TypeScript source for the API/admin page, shared domain and authorization layer, MCP stdio server, ingestion/provisioning scripts, tests, deterministic starter fixtures, generated dev/staging/prod manifests, CI workflow, and local Claude Desktop/Gemini CLI registration artifacts.

## Verified locally

- `npm ci` completed using Node 22.15.1 and npm 10.9.2.
- `npm run lint` and `npm run build` completed (`tsc --noEmit`).
- `npm test` passed: 2 files and 11 tests.
- `npm run setup` ingested 2,336 normalized facts and rendered provisioning output.
- A second ingestion was exercised by the integration test and kept the fact count at 2,336.
- `npm run provision` rendered dev, staging, and prod permissions/host-registration files.
- `npm run validate:provisioning` passed.
- REST smoke tests were executed locally for health, identity, usage summary, top users, capability status/update, invalid-period rejection, disabled-connector behavior, and cross-group denial.
- MCP stdio smoke tests were executed locally: the server listed exactly the four required tools, allowed an own-group summary, denied a Clinical Operations lead requesting Finance data without returning Finance facts, and rejected an invalid period.
- Claude Desktop JSON and Gemini extension JSON parse as valid JSON and reference the local MCP command; their setup documents are included.

## Partially verified

- The browser-admin page is served by the local API and its backing endpoints were runtime-tested; a manual browser visual review is not represented as an automated test.
- Generated manifests were checked by the provisioning validation command. They are regenerated by `npm run provision`, rather than hand-edited.

## Not verified locally

- Claude Desktop was not launched or connected to this server.
- Gemini CLI was not launched or registered against this server.
- No real identity provider, Claude Enterprise account, Vertex AI/BigQuery account, or external connector registry was used. All identities and usage data are deterministic supplied fixtures.
